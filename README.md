# Rent-A-Car Business Management System

এটি একটি সম্পূর্ণ গাড়ি ভাড়া ব্যবসা পরিচালনা সিস্টেম যা PHP, MySQL এবং HTML/CSS দিয়ে তৈরি।

## প্রজেক্ট ফিচার

### ১. ইউজার ম্যানেজমেন্ট
- তিন ধরনের ব্যবহারকারী: Admin, Employee, Customer
- সিকিউর লগইন এবং রেজিস্ট্রেশন সিস্টেম
- প্রতিটি রোলের জন্য আলাদা ড্যাশবোর্ড

### ২. গাড়ি ম্যানেজমেন্ট
- গাড়ি যোগ, সম্পাদনা এবং মুছে ফেলা
- গাড়ির তথ্য (মডেল, ব্র্যান্ড, রঙ, সিট, জ্বালানি ইত্যাদি)
- স্ট্যাটাস ট্র্যাকিং (উপলব্ধ, ভাড়া নেওয়া, রক্ষণাবেক্ষণ)
- দৈনিক ভাড়ার মূল্য নির্ধারণ

### ৩. বুকিং সিস্টেম
- গ্রাহকরা গাড়ি ভাড়া নিতে পারেন
- পিক-আপ এবং ড্রপ-অফ লোকেশন সিলেক্ট করুন
- স্বয়ংক্রিয় খরচ গণনা
- বুকিং স্ট্যাটাস ট্র্যাকিং

### ৪. পেমেন্ট সিস্টেম
- একাধিক পেমেন্ট পদ্ধতি সমর্থন
  - নগদ
  - কার্ড
  - মোবাইল ব্যাংকিং
  - ব্যাংক ট্রান্সফার
- পেমেন্ট স্ট্যাটাস ট্র্যাকিং
- ইনভয়েস জেনারেশন

### ৫. গ্রাহক ম্যানেজমেন্ট
- গ্রাহক প্রোফাইল ম্যানেজমেন্ট
- ড্রাইভিং লাইসেন্স তথ্য সংরক্ষণ
- গ্রাহক ইতিহাস
- রিভিউ এবং রেটিং সিস্টেম

### ৬. রক্ষণাবেক্ষণ ম্যানেজমেন্ট
- গাড়ির রক্ষণাবেক্ষণ তথ্য সংরক্ষণ
- রক্ষণাবেক্ষণ খরচ ট্র্যাকিং
- রক্ষণাবেক্ষণ সিডিউল

### ৭. ক্ষতি রিপোর্ট
- গাড়ির ক্ষতি রিপোর্ট করুন
- ক্ষতির তীব্রতা রেকর্ড করুন
- ক্ষতি খরচ গণনা

### ৮. রিপোর্টিং এবং বিশ্লেষণ
- বিক্রয় রিপোর্ট
- গাড়ি ব্যবহার বিশ্লেষণ
- গ্রাহক বিশ্লেষণ
- আয় ট্র্যাকিং

## ইনস্টলেশন নির্দেশাবলী

### ১. ডাটাবেস সেটআপ

```sql
-- ডাটাবেস তৈরি করুন
CREATE DATABASE car_rental_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- স্কিমা ইমপোর্ট করুন
mysql -u root -p car_rental_db < database/schema.sql
```

### ২. কনফিগারেশন সেট করুন

`config/config.php` ফাইলে আপনার ডাটাবেস তথ্য সেট করুন:

```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'car_rental_db');
define('DB_USER', 'root');
define('DB_PASSWORD', '');
```

### ৩. ওয়েব সার্ভার চালান

```bash
php -S localhost:8000
```

### ৪. ব্রাউজারে খুলুন

```
http://localhost:8000
```

## প্রযুক্তি স্ট্যাক

- **Frontend**: HTML5, CSS3, JavaScript
- **Version Control**: Git
